### What I work on

I train models on signals that are hard to label and easy to overfit. Most of my work
lives in the gap between a spectrogram and a claim you can defend: **honest validation
protocols, corrected significance tests, and pipelines that reproduce bit-for-bit.**

| Thread | What it is |
| :-- | :-- |
| **Biomedical signals** | Parkinson's detection from handwriting dynamics — time–frequency encodings, repeated nested CV |
| **Italian SLMs** | Post-training sub-1B Italian models; benchmark-driven, fully auditable runs |
| **Industrial signals** | Engine knock detection from in-cylinder pressure — transfer across operating conditions |
| **IoMT / IDS** | Intrusion detection on medical-device network traffic |
